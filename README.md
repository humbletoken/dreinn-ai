# Dreinn AI

Telegram-бот с Mini App: чат с нейросетями, генерация изображений и видео, профиль и админ-панель.
Сервер и бот — один файл `bot.js`, база SQLite, npm-пакеты не нужны (Node.js 22.13+).

## Как устроено

- **Бот.** На `/start` и любое сообщение присылает баннер, короткий текст и кнопку «Открыть». Баннер, текст и кнопка настраиваются в админке. Других команд нет.
- **Mini App:**
  - «Чат» — диалоги с моделями. Сверху выбор модели по типам: чат, изображения, видео. Ответ печатается по мере генерации, есть кнопка «Стоп». Можно прикрепить фото. Чаты сохраняются, список открывается кнопкой слева.
  - «История» — запросы и операции с балансом.
  - «Инфо» — описание, цены, вход для администратора.
  - «Профиль» — аватарка, цвет и фон профиля Premium, эмодзи-статус, переводы баланса, рефералка.
- **Админ-панель** (в Mini App у админов и в браузере по паролю):
  - модели трёх типов: цена за запрос, промпт, формат API, тест;
  - пользователи и выдача баланса;
  - премиум-эмодзи: импорт паков и замена иконок в разделах;
  - баннеры и тексты, рассылка, статистика.

Пополнение пока вручную: админ выдаёт баланс («Люди» → «Выдать баланс»). Тип «Пополнение» начисляет пригласившему реферальный процент, «Бонус» — нет. Оплата через СБП будет позже.

### Форматы API моделей

| Тип | Формат | Эндпоинт |
|---|---|---|
| Чат | Anthropic | `/v1/messages` (стриминг) |
| Чат | OpenAI | `/v1/chat/completions` (стриминг) |
| Изображения | OpenAI Images | `/v1/images/generations`, с фото — `/v1/images/edits` |
| Изображения | Картинка в ответе чата | `/v1/chat/completions` (Gemini, OpenRouter и т. п.) |
| Видео | OpenAI Videos | `/v1/videos` → ожидание → `/v1/videos/{id}/content` |

Размер, длительность и прочие параметры задаются в поле «Доп. параметры (JSON)» у модели, например `{"seconds":"8","size":"1280x720"}`.

## Деплой на bothost.ru

1. Возьми архив `dist/dreinn-ai-bothost.zip` (или залей папку в Git-репозиторий).
2. В панели bothost: «Создать бота» → платформа Telegram, язык Node.js, токен бота → загрузи архив.
3. В «Дополнительных настройках»:
   - включи **«Использовать собственный Dockerfile»** — так бот запустится на Node.js 24 со встроенным SQLite;
   - включи **«Использовать домен»** и задай поддомен, например `dreinn.bothost.ru`. Mini App работает только по https;
   - внутренний порт — **3000**.
4. В «Переменных окружения» добавь:

   | Переменная | Значение |
   |---|---|
   | `AI_API_KEY` | ключ провайдера нейросетей |
   | `AI_BASE_URL` | `https://vibecode.moe` (по умолчанию) |
   | `ADMIN_PASSWORD` | пароль админки |
   | `ADMIN_IDS` | твой Telegram ID (необязательно) |
   | `PUBLIC_URL` | `https://dreinn.bothost.ru` — если bothost не подставил `DOMAIN` сам |

   `BOT_TOKEN` bothost подставляет сам. Если на тарифе нет переменных окружения, положи в архив файл `.env` по образцу `.env.example` — `bot.js` прочитает его.
5. Задеплой. В логах должно быть `✔ @DreinnAI запущен` и `Mini App: https://…`.
6. Открой бота, нажми `/start` → «Открыть». Чтобы стать админом: «Инфо» → «Вход для администратора» → пароль. В админке загрузи баннер для `/start` («Настройки» → «Бот»).

База и файлы хранятся в `/app/data` — эта папка переживает перезапуски и обновления. На бесплатном тарифе bothost данные стираются при рестарте, для продакшена нужен тариф с постоянным диском.

## Запуск локально

```bash
cp .env.example .env   # заполни токены
node bot.js
```

Сайт и админка будут на `http://localhost:3000`. Без https-адреса в `PUBLIC_URL` кнопка «Открыть» в боте не появится. Если Telegram заблокирован, бот на Windows сам возьмёт системный прокси (v2rayN и т. п.); иначе задай `PROXY_URL`.

### Docker

```bash
docker build -t dreinn-ai .
docker run -d --name dreinn --env-file .env -v dreinn-data:/app/data -p 3000:3000 dreinn-ai
```

Или `docker compose up -d --build`.

## Переменные окружения

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (на bothost подставляется сам) |
| `PUBLIC_URL` | адрес Mini App с https; если пусто — берётся `https://$DOMAIN` |
| `AI_BASE_URL`, `AI_API_KEY` | провайдер нейросетей; у модели можно задать свои |
| `ADMIN_IDS` | Telegram ID админов через запятую |
| `ADMIN_PASSWORD` | пароль админки (в Mini App и в браузере) |
| `PORT`, `HOST`, `DATA_DIR`, `TIMEZONE` | сервер, папка с данными, часовой пояс |
| `WEBHOOK=1` | webhook вместо long polling (нужен `PUBLIC_URL`) |
| `POLLING=0` | только сайт, без приёма апдейтов (второй экземпляр) |
| `PROXY_URL` | прокси для Telegram и нейросетей |

## Премиум-эмодзи

- Импорт: админка → «Эмодзи» → ссылка `t.me/addemoji/имя` или ID. Ещё проще — пришли боту сообщение с премиум-эмодзи: от админа они сразу попадают в библиотеку.
- Замена: «Эмодзи» → «Иконки разделов» → «Заменить». Работает для меню и разделов приложения, типов моделей, иконок моделей, эмодзи в тексте бота и на кнопке «Открыть».
- Анимированные (TGS) рисуются через lottie, видео (WEBM) — тегом `<video>`, статичные (WEBP) — картинкой.
- В сообщениях бота премиум-эмодзи видны, только если у владельца бота Telegram Premium. Без него выключи «Премиум-эмодзи в боте» в настройках.
